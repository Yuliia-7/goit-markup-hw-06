# WebStudio

A responsive landing and portfolio website for a web design and development studio, built from a Figma layout.

## 🔗 Live Demo
[View Live Page](yuliia-7.github.io/goit-markup-hw-06/)

## 🛠 Tech Stack
- **HTML5** (semantic markup)
- **CSS3** (Flexbox, responsive media queries, smooth transitions)
- **BEM methodology**

## ✨ Key Features
- Mobile-first adaptive design across mobile, tablet, and desktop breakpoints
- Interactive modal window for service orders and mobile navigation menu
- Filterable portfolio section and newsletter subscription form
